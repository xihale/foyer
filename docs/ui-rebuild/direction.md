# foyer 界面：门厅名牌

用户来首页是找一个服务、看它在不在。不是来看介绍。

北极星：站在门厅名牌前，扫一眼谁在、谁不在，然后推门进去。

调性：安静、对齐严格、一行一个名字。只有离线才提高音量。

和 Homepage / Glance / Homarr 的差别：不铺壁纸，不做玻璃卡片，不做三栏信息流，不做图标磁贴。健康是名字左边的一道刻痕，不是绿灯。

色彩来自石灰石和刻字，不来自自托管面板常见的黑底青绿色。

- 石 `#d9ddd4`，暗处 `#1c211c`
- 墨 `#1c211c`，暗处 `#e7eadf`
- 镉橙 `#c2410c`（暗处 `#e07a3d`）只铺在离线那一行

字体：衬线名牌（Noto Serif CJK SC 及宋体回退）。延迟和百分比用等宽数字。

动效：按下时行向右让 2px；离线的镉橙从左侧刻痕铺开。列表不做入场动画。页面之间走客户端导航，不整页重载。页头吸顶常驻，滚动与换页都不移动；正文与页头共用 48rem 栏宽和同一内边距，三页的页头高度、正文起点一致。页头高度写死（--header-bar-h 56px + 1px 下边框 = 57px），手机第二行恒为 46px（合计 103px）：槽里的搜索框、切换器、分区条内容再变也撑不高页头。标题过长只在本栏内截断，不挤右栏导航的位置；手机分区条六个入口收在一行（360px 起放得下），更窄才横向滑动。


评审一轮，8/10。随后改了：监控图例和格子用同一套方块；格子等高，能数；监控列表改成和首页一样的分组顺序；在线刻痕加粗；手机上的延迟用正文色，说明用次级色；禁用的「进入」是一块静音名牌，不再发灰透明。

证据：`docs/ui-rebuild/shots/home-desktop`、`home-phone`、`status-desktop`、`admin-desktop`。标杆原图在 `docs/ui-rebuild/benchmarks/`。
没做：管理台登录后的各表单仍沿用同一套控件，没有改成另一套信息架构。404 在开发服务器里由 Vite 接管，正式环境走应用自己的页面。
